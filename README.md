# PNG_inference
All-in-one PNG inference -- A stable inference interface for primordial non-Gaussianity analyses, with interchangeable inference backends and reproducible backend provenance.

Currently this repo is under active development, see [docs/dev_notes](./docs/dev_notes.md) for the development status and roadmap.

## Notes on NERSC environment

Always run `source .env.sh` to set up the environment variables when open a new terminal.
